# Sources de données

BigMap s'appuie exclusivement sur des **données officielles et publiques**. Aucune donnée
privée ni scrapée de manière non autorisée.

---

## Sources

| Source | Ce qu'elle apporte |
|---|---|
| **INSEE Filosofi** | revenu médian par commune |
| **INSEE SIRENE** | dates d'ouverture, référentiel des établissements de restauration |
| **Base Adresse Nationale (BAN)** | géocodage des adresses |
| **geo.api.gouv.fr** | communes, intercommunalités, contours administratifs |
| **OpenStreetMap / Overpass** | positionnement précis au bâtiment |
| **OpenRouteService** | calcul des isochrones routières (zones de chalandise) |
| **CARTO** | fonds de carte (tuiles) |
| **Leaflet** | bibliothèque d'affichage cartographique |

Fonds de carte © OpenStreetMap, © CARTO.

---

## Couverture et qualité

| Indicateur | Taux |
|---|---|
| Restaurants positionnés précisément (bâtiment / numéro de rue) | 90 % |
| Restaurants avec revenu médian de la commune | 99,8 % |
| Restaurants avec population et densité | 100 % |
| Restaurants avec date d'ouverture | 88 % |

Quand une donnée n'est pas disponible dans les sources, elle reste **vide** : BigMap ne
l'estime jamais à la place des sources.

---

## Chiffres d'affaires

Les CA annuels (2021-2025), le nombre de commandes et le ticket moyen sont des
**estimations** reconstituées à partir des sources publiques disponibles. Ils sont
fournis à titre indicatif, pour comparaison entre emplacements, et affichés uniquement
là où la donnée peut être établie.
